# 篇章与世界观设定 · Earth Online

> 这一份是「文学性」的部分。写法偏高想象、略带温度，但在数据结构上每一个字段都是可判定的。
> 设计原则：**篇章不是关卡，是玩家对自己人生阶段的命名权。**

---

## 一、为什么需要 Chapter

如果终极目标是 [A9资产 / 海外身份 / 私人Lab / 地理无关工作 / 灵魂伴侣]，
那么玩家在第一天看到它们时，只会感到**遥远**。Chapter 的作用是把「遥远」翻译成
**「我现在正走在哪一段路上」**——它不降低难度，它提供坐标。

篇章推进条件全部是**客观可验证**的（等级、天数、资产量级、事件触发），
不依赖 AI 主观判断。AI 只负责在每个篇章里生成任务内容。

**主线不是一条线，是一张网。** 玩家的真实人生里，学术、世界、资本三条支线
本来就并行推进，在关键节点汇回主干；「同频者」从第一天起就可以开始：

```
                        ┌─ Ch.2 把名字写进引文 ─┐
                        │        （学术支线）     ├─ Ch.4 把问题磨成针 ─┐
   Ch.1 课表之外 ───────┼─ Ch.3 候鸟的第一段航程 ─┘     （任一即可）       │
                        │        （世界支线）                            ├─ Ch.6 无锚之船 ─ Ch.7 白墙与服务器 ─ Ch.9 点亮进化树
                        ├─ Ch.5 河流开始改道 ──────────────────────────┘    （汇流点②）         （汇流点③）
                        │        （资本支线）
                        └─ Ch.8 同频者（从 Ch.1 起全程并行，不参与汇流）
                                 （关系支线）
```

四条规则：

1. **支线顺序自由、可并行**：先海外研究再产出论文（Ch.3 → Ch.2）是合法的；
   一边科研一边积累财富（Ch.2 / Ch.4 ∥ Ch.5）也是合法的。
   代码里体现为 `requires`（全部完成才解锁；Ch.4 例外，`requiresOneOf` 二选一）
   与多个同时活跃的章节。
2. **汇流点的门槛是「至少一条线走到了」**：Ch.4 只要 Ch.2 或 Ch.3 任一完成即开启
   ——先跑通一段研究、或者先出去看一次，都足以进入。
   另一条线不构成门锁：它随时可以作为支线补上，而不是必须先交的作业。
3. **Ch.8 永不作为前置**：一个人不该因为还单身，而被卡住任何一件事。
4. **幕只是展示分组**：3 幕（求学 / 立业 / 造物）只用于履历视图，
   不参与解锁判定。

## 二、篇章目录（9 章 · 3 幕；幕仅为展示分组）

### 第一幕 · 求学

#### Ch.1 「课表之外」

> *"你还不知道要去哪。但你已经开始把时间，花在四年后还留着的东西上。"*

- **支线**：主干起点
- **副标题**：校园、副业与第一笔自己赚来的钱
- **主题**：同样的四年，学分是下限，课表之外的时间才是上限。
  一边把专业基础打扎实，一边用副业和兼职换取第一本金与最早的现实感。
- **进入**：游戏开始
- **离开**：连续 30 天有记录；≥1 条职业线达 Lv.5；出现第一笔自己赚来的钱
- **主推目标**：地理无关工作、A9 资产（起步）
- **情绪基调**：干净、有点穷但很自由、图书馆闭馆时的风。
- **玩家在此章学到的**：记录 > 灵感；节律 > 强度。

#### Ch.2 「把名字写进引文」

> *"在人类知识的墙上，先钉下第一枚属于你的钉子。"*

- **支线**：学术支线
- **副标题**：本科科研与第一次真实产出
- **主题**：从「学这门课的人」变成「做过一件可被检验的事的人」。
  哪怕只是一份复现、一个开源工具、一份数据集——只要它真实存在、能被别人使用，
  性质就完全不同了。
- **进入**：Ch.1 完成（学术支线开启；可与 Ch.3 / Ch.5 / Ch.8 并行）
- **离开**：产出 ≥1 项可被外部检索/使用的成果（预印本 / 开源仓库 / 公开数据集 / 会议投稿）
- **主推目标**：私人独立 Lab（前身）
- **情绪基调**：专注、第一次被审稿人或用户认真对待。

#### Ch.3 「候鸟的第一段航程」

> *"第一次独自过海关的时候，你会发现自己其实很小，但也很完整。"*

- **支线**：世界支线
- **副标题**：第一段海外经历
- **主题**：把「世界」从一个词变成一个具体的房间、一条街、一种说不利索的语言。
  这段经历的价值不在于履历上多一行，而在于你从此知道自己在陌生环境里能活成什么样。
- **进入**：Ch.1 完成——**不要求先走完 Ch.2**。先海外研究、再产出论文，
  正是这张网允许（甚至是鼓励）的走法。
- **离开**：完成 ≥1 段不少于 8 周的海外学习/研究经历，并在当地独立完成一件完整的事
- **主推目标**：全球通行海外身份、地理无关工作
- **情绪基调**：开阔、陌生、语言不够用但活下来了。

#### Ch.4 「把问题磨成针」

> *"把一个含糊的困惑，磨成一根能扎穿它的针。"*

- **支线**：学术支线 · **汇流点①（学术 / 世界任一入口）**
- **副标题**：研究生阶段与学术能力的成型
- **主题**：研究生不是延长学生时代，而是第一次真正拥有一个属于自己的问题。
  你要学会把它磨得足够细、足够具体，细到别人绕不过去——它就成了你的。
- **进入**：Ch.2 或 Ch.3 **任一完成**即可进入；另一条线随时可补
  （先海外研究、再产出论文，或反过来，或只走其中一条——都合法）
- **离开**：研究生阶段产出 ≥1 项可作为第一作者的成果，且方法论可被他人复用；
  如再有第二段海外经历，额外计入进度
- **主推目标**：私人独立 Lab、地理无关工作
- **情绪基调**：深潜、枯燥中的锋利、开始有自己的方法。

### 第二幕 · 立业

#### Ch.5 「河流开始改道」

> *"钱不是目标，是让选择自由的燃料。"*

- **支线**：资本支线
- **副标题**：财富的数量级跃升
- **主题**：从「用时间换钱」转向「用系统换钱」。建立第一个正期望系统，
  让收入第一次不依赖出勤。
- **进入**：Ch.1 完成（可与学术线**全程并行**——一边科研，一边积累财富）
- **离开**：出现 ≥1 条非工资性收入，且净资产相对进入本章时的基线提升 10 倍
- **主推目标**：A9 资产
- **情绪基调**：冷静、概率思维、戒掉赌性。

#### Ch.6 「无锚之船」

> *"自由不是没有锚，是你自己决定抛在哪里。"*

- **支线**：主干 · **汇流点②（学术 × 世界 × 资本）**
- **副标题**：海外身份与地理自由
- **主题**：把「地理位置无关」从一种工作方式，变成一件写在证件上的事实。
- **进入**：Ch.4 与 Ch.5 均完成
- **离开**：海外身份进程实质推进至递交或获批，且已完成 ≥1 段长期异地工作验证
- **主推目标**：全球通行海外身份、地理无关工作
- **情绪基调**：开阔、漂泊感与掌控感并存。

### 第三幕 · 造物

#### Ch.7 「白墙与服务器」

> *"给自己买一间房，四壁皆白，中间放一台只属于自己的机器。"*

- **支线**：主干 · **汇流点③（学术 × 资本 × 自由合流）**
- **副标题**：私人独立 Lab
- **主题**：从租用别人的设备，到拥有提问的自由。
- **进入**：Ch.6 完成
- **离开**：Lab 实体/虚拟形态落地，并产出 ≥1 项独立成果
- **主推目标**：私人独立 Lab
- **情绪基调**：沉静、器物感、造物主的清晨。

#### Ch.8 「同频者」

> *"你终于有能力，去遇见那个不需要你解释的人。"*

- **支线**：关系支线（全程并行）
- **副标题**：灵魂伴侣与深度连接
- **主题**：把自己变成一个值得靠近的人，然后**允许**关系发生。
- **进入**：Ch.1 完成后的任意时刻。它不阻塞任何一条线，也不被任何一条线要求——
  你不必等事业线走完，也永远不会因为它而卡住别的事。
- **离开**：建立 ≥1 段双向深度关系（`warmth` 与 `trust` 双高 + 长期稳定）
- **主推目标**：灵魂伴侣
- **情绪基调**：温暖、不焦躁、不功利。
- **特别约束**：本篇章禁止一切效率化/攻略化措辞。不拆解关系本身，
  只允许拆解**「成为更好的自己」**这一侧。

#### Ch.9 「点亮进化树」

> *"你不再追光。你成为光源本身。"*

- **支线**：主干（隐藏）
- **副标题**：至高隐藏目标
- **进入**：Ch.7 完成，且隐藏条件触发（`evolution.revealed` 由后台累积自动置真；
  不满足时即使 Ch.7 已完成，它也不可见）
- **主题**：不主动领取、不显示进度、无任何 UI 提示——直到某一天它自己亮起来。
- **离开**：不设终点。此后进入 `Endless` 模式，进化树继续生长。
- **情绪基调**：**震撼**。这是整个产品唯一允许「打破沉浸」的时刻。

## 三、至高隐藏目标：人类科技进化树

### 触发哲学

> 玩家永远无法「点击」进入这一章。
> 它由 Arbiter 在每次复盘时静默抽取 `milestoneTags` 累积而来。
> 玩家可能连续数月甚至数年不知道自己正在点亮什么——然后某天打开 App，
> 背景里某一扇窗，不再是暗的。

### 六条分支

| Branch ID         | 中文名   | 意象              | 最高维度的那个节点           |
| ----------------- | ----- | --------------- | ------------------- |
| `COMPUTE_BIOLOGY` | 生命的计算 | 把细胞读成代码，把代码写回细胞 | **AlphaFold 量级的方法** |
| `INTELLIGENCE`    | 心智的镜像 | 造一面能照见自己的镜子     | 一个被真实世界信任的系统        |
| `MEDICINE`        | 衰老的边界 | 让时间慢下来一点点       | 逆转一个可测量的衰老指标        |
| `ENERGY`          | 能量的驯服 | 让每一瓦特都听话        | 让损耗下降一个数量级          |
| `MATERIALS`       | 物质的编织 | 在原子尺度上做手工       | 让材料自己找到结构           |
| `SPACE`           | 出走与远望 | 人类的第二个故乡        | 让一次发射因为你的计算而不同      |

### 五级阶梯（成就维度刻意拉高）

| tier | 名称     | 含义                   | 现实参照             |
| ---- | ------ | -------------------- | ---------------- |
| 1    | **解语** | 能读懂人类已有的答案，并亲手跑通     | 复现一篇前沿工作         |
| 2    | **复现** | 亲手把答案完整做一遍，且别人也能跑通   | 交付一条可复用的流水线      |
| 3    | **改良** | 让答案比原来更好，且被独立验证      | 你的方法被同行验证有效      |
| 4    | **提问** | 提出一个还没有答案的问题，并让别人也想问 | 你定义了一个新问题        |
| 5    | **点亮** | 你的答案成为别人的起点          | **AlphaFold 量级** |

> **tier 3 往上不是「再努力一点」就能到的。**
> 一个 tier 5 节点可能耗掉一个人十年。
> 这正是设计意图——它是至高隐藏目标，不是周任务。
> 如果一个节点能在三个月内点亮，那它就不该叫「点亮」。

### 揭示时机

四个揭示条件（满足任一即显形）：
累计里程碑 15 条 / 已点亮节点 3 个 / 已触及分支 3 条 / 抵达 Ch.7。

按正常节奏，这大约是**持续产出 1~2 年之后**。
阈值刻意设得"玩家不可能猜到"——猜到就不叫惊喜了。

### 高维标签的稀缺性

`paradigm`（改变了领域的工作方式）、`flight_heritage`（成果被真实航天任务采用）、
`scale`（真实规模验证）这类高维标签，在词表里是存在的，但 Arbiter 被明确要求：
**不要因为任务听起来厉害就打**。误打一个高维标签，
等于让一个本该十年后才亮的节点虚亮——那比不亮更糟。

## 四、现实里已经发生的事：现实里程碑

有些「任务达成」不发生在 App 里，而是发生在世界里：
签证递交、第一次独自过海关、一段海外旅行、论文被接收、第一笔自己赚来的钱。

它们**不走任务状态机**——没有「领取 → 执行」的过程，因为它们已经发生了。
玩家在「记录一件事」面板里自行声明，系统校验冷却与月度上限后，
直接发放一笔固定的 EXP，并点亮对应的终极目标里程碑。

> **为什么要给这些事留位置？**
> 如果只有「计划内的事」被奖励，那些真正改变了轨迹的时刻就会被漏掉——
> 递出签证材料的那天，其实比很多任务都重。
> 但它的性质是「记录」，不是「打卡」：额度刻意小（80~500），
> 因为它的价值不在 EXP，而在它点亮的那一格目标里程碑。

| 类别      | 条目速览                                                                 | EXP     |
| ------- | -------------------------------------------------------------------- | ------- |
| 移动与世界   | 第一次独自过海关 / 一段海外旅行（不限次数）/ 完成一段海外经历（180 天冷却）/ 语言的钥匙 / 材料成形 / 递交 / 获批 / 落地生根 | 100~400 |
| 纸与成果    | 独立复现一项结果 / 成果公开 / 论文投稿 / 论文被接收 / 在会议上做报告                             | 120~500 |
| 第一块钱    | 第一笔自己赚的钱 / 第一个付费客户 / 第一笔远程收入                                         | 200~250 |

几处设计细节：

- **一次性事件不可重复记录**；可重复的条目里，旅行不限冷却（每段真实发生的旅程
  都值得记录），海外经历设有 180 天间隔。
- **月度 EXP 总上限 1200**（`RewardPolicy.realityMilestoneMonthlyExpCap`），防刷。
- 部分条目与篇章离开条件直接对应：
  「完成一段海外经历」↔ Ch.3 的离开条件；
  「递交 / 获批」↔ Ch.6 的离开条件。
  Phase 3 的章节判定会**同时检查任务完成与里程碑记录**。
- **快照**：记录时可以附一张照片（签证页、登机牌、接收邮件）。
  系统会在客户端把它压成小图存进档案——之后每一次回看，
  它不再是一行绿字，而是一个可以点开的瞬间。记录当下没拍的，之后也可以补。
- 「获批」与「论文被接收」这类事件附带 1 点属性点——
  它们是那种会让人安静下来坐一会儿的时刻。

## 五、玩家可见的命名权

每完成一个篇章，玩家可以为**下一章**选择代号（从 3 个候选里挑，或自己写）。
这个代号会出现在 HUD 与成功日记的页眉。理由：
**这不是一款量化你的 App，而是一款让你为自己的阶段命名的 App。**
